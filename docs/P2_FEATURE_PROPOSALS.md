# P2 新增任务需求草案

两项各由一人负责，从实现到本机真实调试、评审收尾均由负责人完成。本草案先按任务名称评审，编号与领取状态待确认后登记到主任务表。以下为建议分工和首版验收范围。

| 负责人 | 任务 | 可交付成果 | 确有依赖的事项 |
| --- | --- | --- | --- |
| B | 私人宠物 Vlog | 本地单用户图文与短视频时间线 | 复用已有宠物 API。多用户上线需要真实身份体系 |
| C | 高德真实底图 | 附近页道路底图与地点列表联动 | 高德 JS API 配置。真实 POI 联验需要现有 P1-9 服务和可用 Key |

## B · 私人宠物 Vlog

**单用户本地版可行。** B 一次负责后端和最小前端页面，页面沿用现有记录页的宠物选择、表单和时间线样式。使用真实宠物 API 的 ID，与既有疫苗、驱虫、体重等记录分开。支持按宠物查看时间线，以及创建、修改文案与日期、删除。首版每篇选传最多 3 张 JPEG/PNG（每张 5 MB）或 1 段兼容浏览器的 MP4（20 MB），数值为工作量估算用的默认值。

- 沿用 FastAPI、Pydantic、SQLAlchemy 和 Alembic。建议新增 GET/POST /api/v1/vlogs、PATCH/DELETE /api/v1/vlogs/{id}，以及经应用路由读取的媒体地址。创建用 multipart，编辑用 JSON。首版替换媒体可删除后重建。
- 复用 FastAPI UploadFile、Starlette 文件响应和浏览器原生视频控件。校验文件大小、实际格式和宠物归属，使用生成的存储键。数据库保存条目及文件元数据，媒体放在仓库外的本地私有目录或已忽略的运行目录。上传失败清理临时文件，删除条目后回收媒体。删除宠物时同步处理关联媒体，回收失败可重试。
- 本地版限回环环境使用，借用当前单用户数据模式。共享部署前另行补齐真实身份、媒体访问隔离、位置元数据清理和私有存储。首版采用浏览器兼容格式，不引入转码服务。

**本机完成标准**：运行真实前后端，用真实宠物 ID 上传样例图片和视频，刷新后可浏览及播放，修改和删除生效。检查过大或格式错误、断开上传后重试、删除后媒体不可访问。[FastAPI 上传实现](https://github.com/fastapi/fastapi/blob/master/docs/en/docs/tutorial/request-files.md)

## C · 高德真实底图

**可行，地点数据由现有附近服务提供。** C 在 NearbyPage 替换现有位置示意图，沿用 nearby Client、NearbyResponse、三类地点及半径筛选。优先评估高德官方加载器和官方标记示例。列表选中定位标记，点击标记选中列表项。SDK 加载失败仍可操作列表，离开页面清理地图实例。

- 按 P1-7 草案，业务接口使用 WGS84，前端只在绘制查询中心和标记时转为 GCJ-02。地点搜索、距离排序和数据源继续沿用后端，展示 source、search_center 和 fallback_reason。首版拖动地图只调整视图。
- JS API 安全密钥由服务端代理注入。C 可先用真实底图配合明确标注的演示地点调试。主分支已有 P1-9 真实 POI 查询及联调记录，使用现有后端核验真实坐标和来源，无须另建搜索接口。

**本机完成标准**：在实际浏览器打开高德底图，核验地标位置、列表双向联动、定位被拒及 SDK 失败时的页面行为。只有连通真实 POI 后才登记真实地点联验通过。P1 后端暂不可用时，分别记录底图完成与真实 POI 联验待办。[高德 JS API 快速上手](https://lbs.amap.com/api/javascript-api-v2/getting-started)、[安全密钥代理](https://lbs.amap.com/api/maps-javascript-api/guide/abc/jscode)

## 开源复用与收尾

1. 领取后先对照现有接口、前端类型和项目锁定的依赖。优先复用现有组件、官方示例或小型开源库，选定后记录来源、版本和许可证。直接引用代码时保留许可证要求的声明。
2. 各负责人把自己的任务做到可在电脑上运行，按上面的场景真实调试，再提一份交付供评审。接口有新增时在同一交付更新 API 文档。外部账号或既有任务的依赖单独记清楚，能独立验收的部分先完成。
3. 评审只处理影响验收、接口兼容或数据安全的阻塞项。非阻塞意见记录后直接收尾，无需重新评审。按任务表规则，代码合并并通过必要验证后标为已完成。
