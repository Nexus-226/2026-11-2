# 仓库核对：黑客松脚手架与待办

核对范围：架构指南、原始项目骨架，以及当前功能分支上的三天黑客松脚手架。模拟能力不等于生产接入已经完成。

| 项目 | 当前状态 | 下一步 |
|---|---|---|
| React + TypeScript + Vite | 宠物、聊天、附近服务三个演示入口；API Client、基础测试和构建通过 | C 补宠物编辑/删除交互、真实地图组件与更完整测试 |
| FastAPI | `/health`、宠物 CRUD、同步聊天和附近服务模拟接口已实现 | B 收敛统一错误外壳并接 SQLite Repository |
| Agent 与工具 | 后端进程内 Runtime、显式白名单和工具结果状态已实现 | A 接 LLM Provider、超时与调用次数上限 |
| 业务和数据 | `PetService` 使用内存仓库并内置演示宠物 | B 用 SQLite/Alembic 替换内存仓库，不改变服务契约 |
| 会话和模型 | 会话 ID 与同步回复契约已预留，回复目前为确定性模拟 | A/B 接模型和会话存储；流式输出仍延期 |
| 地图（P1） | 模拟地点、WGS-84/GCJ-02 边界和手动地址回退已实现 | B 接真实高德 Adapter，C 补定位授权和地图渲染 |
| 文档和配置 | README、架构、API、任务、PR、技术栈和 `.env.example` 已有 | 接入真实服务时同步更新字段与安全说明 |
| 测试 | 后端契约/服务测试、前端 API 客户端测试与生产构建已通过 | 增加持久化、错误路径和端到端测试 |

P0 的可演示链路已经具备，但当前存储和回复均为开发期实现，不应描述为生产能力。统一错误、SQLite 迁移、真实 LLM、取消/超时和完整端到端测试仍待完成。P1 只提供明确标注的数据与位置边界骨架，尚未使用真实高德配额。

接口字段和职责以 [API.md](API.md)、[ARCHITECTURE.md](ARCHITECTURE.md) 与 [TECH_STACK.md](TECH_STACK.md) 为准，变更前由三人共同评审。
