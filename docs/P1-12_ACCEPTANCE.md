## 发现与剩余动作

### A-01：未配置高德时，真实模型给出无效恢复建议

真实样本先说明“高德服务未配置、当前演示结果不反映实际服务分布”，随后建议启用定位权限或输入地址以获得真实附近信息。缺 Key 时这两种方式不能恢复真实高德查询，建议会误导用户。开头还使用未限定演示范围的“未检索到宠物医院”，虽然后文补充了来源，首句也宜明确范围。

请 A 调整回答边界并复验：缺 Key/配额等后端问题应提示服务配置或暂不可用；定位权限问题与后端未配置分开。保留空演示结果与真实无服务的区别。不要将单次正常样本当作模型永不出错。

### A-02：导航能力措辞

浏览器正常回答称当前回复未生成导航链接，可告知其“启用导航功能”。Agent 工具返回 navigation_url=null，当前能用的是页面真实地点卡片的主动导航入口。请 A 确认是否应改为指向已有页面入口，避免暗示聊天能开启未实现能力。此项需审核，不据此声称工具已经支持导航写入。

### C-01：查询中心具体地址展示

选择候选后页面仅显示通用“所选地址”及坐标，没有保留候选 formatted_address 作为当前中心文字。候选列表仍在，但不等于明确的选中中心展示。交 C 单独补修并验证模式切换不残留地址；本次验收不覆盖其他成员在途改动。

### B-01：真实类别与地址匹配准确性需人工复核

关键词召回中出现“宠物服务有限公司”作为医院结果，以及名称含医院的美容结果。实现将查询类别直接写入返回 category，不能仅凭 HTTP 成功证明商家服务分类准确。请 B 结合高德返回类型复核策略；不在本次 C 验收中擅自改后端。地址解析结果与 B/#54 记录一致，但“合法坐标”不能单独证明人民广场匹配准确，需核对候选实际位置。
